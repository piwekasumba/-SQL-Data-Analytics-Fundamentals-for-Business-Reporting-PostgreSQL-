# SQL Data Analytics Fundamentals for Business Reporting — PostgreSQL
---
## Project Overview

This repository documents foundational SQL learning and practice using PostgreSQL.

The project applies core SQL concepts to business-style data questions, with the aim of developing the querying skills needed for further work in reporting and data analysis.

It includes learning exercises and independently organised portfolio material based on simulated business data.
---
## Learning Objectives

The project focuses on understanding how to:

- Retrieve records using SELECT.
- Filter data using WHERE.
- Sort query results using ORDER BY.
- Group records using GROUP BY.
- Calculate totals, counts and averages using aggregate functions.
- Combine related tables using INNER JOIN and LEFT JOIN.
- Understand primary keys and foreign keys.
- Translate simple business questions into SQL queries.
---
## Business-Style Practice

Example practice areas include:

- Customer and policy information
- Insurance claims
- Order values
- Filtering and summarising business records
- Combining related tables to produce useful query outputs
---

- PostgreSQL

## Learning Context

This is a foundational learning project. It is intended to show the development and application of core SQL querying skills.

The project is not presented as advanced analytics, production database administration, professional reporting experience or enterprise data engineering.
---
## Portfolio Progression

This project provides the SQL foundation for more applied work in the portfolio, including retail reporting, insurance claims analysis and SQL-based data preparation.

The progression is from learning core SQL syntax to applying SQL in structured business-reporting scenarios.
